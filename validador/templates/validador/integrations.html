Crear una factura

Reenviar el mismo client_id es idempotente: devuelve la factura existente. Precios con IVA incluido; tax_rate: 13, 4, 2, 1, 0 o exempt.

curl -X POST {{ base_url }}/api/v1/invoices/ \
  -H "Authorization: Bearer gb_TU_KEY" -H "Content-Type: application/json" \
  -d '{
    "client_id": "erp-000123",
    "issuer_name": "Comercial Guanacaste S.A.", "issuer_id": "3101123456",
    "receiver_name": "Cliente de Prueba S.A.", "receiver_id": "3101654321",
    "issue_date": "2026-01-15",
    "lines": [{"description": "Servicio de consultoría", "quantity": 1, "unit_price": "113000", "tax_rate": "13"}]
  }'

Marcar lista y enviar a Hacienda

curl -X POST {{ base_url }}/api/v1/invoices/ID/transition/ -H "Authorization: Bearer gb_TU_KEY" \
  -H "Content-Type: application/json" -d '{"to": "ready", "version": 1}'
curl -X POST {{ base_url }}/api/v1/invoices/ID/submit/ -H "Authorization: Bearer gb_TU_KEY"
curl {{ base_url }}/api/v1/invoices/ID/ -H "Authorization: Bearer gb_TU_KEY"   # estado, clave y respuesta
